# Registro Estudiantes, Manejo De Excepciones

Este proyecto es un registro de estudiantes realizado en C# con Windows Forms. Permite ingresar el nombre, la edad y el correo electrónico. Se utilizan validaciones para verificar que los datos sean correctos antes de guardarlos. Además, se implementó un bloque try-catch para controlar errores y mostrar mensajes cuando algún dato es inválido. También cuenta con opciones para limpiar los campos y salir del sistema.
